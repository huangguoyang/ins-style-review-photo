# 真实场景衍生与系列一致性

## 目标

在「真实生活风格母版 + 产品身份锁」都固定的前提下，沿叙事与生活场景两个轴衍生多个真实场景方案；所有场景共享同一母版与锁块，只有场景/叙事/构图变化，从而保证系列一致、审美一致。

## 两个轴

- **叙事轴（讲什么）**：场景故事、使用情境、情绪节拍、产品在场景中的角色——主角 / 道具 / 使用中 / 与人物互动。每个场景一句话点明叙事。
- **生活场景轴（在哪拍）**：真实生活里的具体场景——书桌、床头、厨房、沙发、阳台、咖啡厅、街拍、手持自拍、通勤、旅行。场景轴从母版继承「场景类型基调」，再落到具体环境。

## 人物互动（本技能的重要场景）

真实生活摄影里，产品常与「人」产生互动。每个场景明确是否有人物，人物如何与产品互动：

- **无人物**：产品静置于真实场景（桌面、床头、窗台、地面）。
- **手部互动**：手持产品、手拿产品展示、手指触碰/按压/倒出/涂抹产品（只出现手/局部，不出整张脸）。
- **人物入镜**：人物使用产品、拿着产品在真实环境里、与产品同框的生活瞬间（自然抓拍感，非摆拍广告）。

人物互动要服从「真实生活摄影」基调：自然、不做作、抓拍感，避免模特摆拍的商业广告感。

## 每个场景方案包含

```text
叙事一句话：...
审美要点：构图/机位/光线情绪/前中后景各一句
产品位置：产品在该场景中的位置、朝向、大小、可见角度
人物互动：无 / 手部（具体动作）/ 人物入镜（具体关系）
完整提示词：...
```

## 系列一致性机制

- 「风格前缀块」在每条提示词**开头原样复用**，锁住拍摄感、成像签名、场景基调、色彩、光线、质感。
- 「产品锁块」在每条提示词**原样复用**，锁住结构、材质、颜色。
- 只有「场景与叙事块」在系列内变化：环境、道具、前中后景、人物互动、情绪、机位。
- 每个场景沿用母版的同一套色彩系统与光线系统；不同场景之间只调「用量」和「落点」，不换系统。

## 场景差异化

在母版一致的前提下做变化，靠这些维度：

- 构图与机位（俯拍桌面 / 平视 / 斜拍 / 手持近景 / 微距特写，负空间分配）。
- 环境与道具（居家/户外/咖啡厅，道具多少），但道具材质与场景质感要服从母版。
- 人物互动档位（无 → 手部 → 人物入镜），生活感递进。
- 情绪节拍（叙事从「静置/开箱」到「使用/互动」）。
- 前中后景层次与产品在画面中的占比。

不靠「换风格」来制造差异。

## 数量与画幅

- 默认画幅 3:4 竖屏；用户可覆盖（1:1、4:5、9:16 等）。
- 未指定场景数量时给 3 个差异化场景；用户要求 N 个就出 N 个。
