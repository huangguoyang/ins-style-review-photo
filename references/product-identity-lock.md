# 产品身份锁与保真防线

## 目标

从产品图提炼「绝不允许改变」的身份清单，转化为正向锁定 + 负向防线 + 自然落地规则，保证成图里产品结构、外观、材质、颜色不变，并且像真实相机在生活场景里拍出来的。这是全技能优先级最高的约束。

## 锁定字段

1. **结构与轮廓**：外形、比例、部件（旋钮/接口/按键/瓶盖/标签/开孔）及其**连接关系**、腿脚/支撑结构、把手/缝线/边缘，logo 与文字的位置、包装与产品本体的关系。
2. **颜色分区**：产品上哪一块是什么颜色（分区而非笼统一色）；固有色 + 近似 HEX；区分「固有色」与「受场景光影响后的观感色」。
3. **材质**：表面材质类型（金属/玻璃/塑料/皮革/织物/陶瓷/纸/木…）、光泽度（磨砂/哑光/镜面/拉丝）、纹理、透明度、反光特性。
4. **品牌元素**：logo、型号文字、标签。默认保持；用户要求隐去时才隐去，并在锁块里写清。

## 材质不变的判定

- 材质类型不变：磨砂金属不能变镜面、玻璃不能变塑料、皮革不能变织物。
- 表面质感不变：拉丝方向、颗粒粗细、反光强弱保持。
- 颜色不变：固有色与颜色分区不变；受光影响的明暗变化允许，色相偏移不允许。

## 生成优先级

当产品结构复杂时，先判断描述优先级：

1. 第一优先：产品整体轮廓、比例、颜色分区、关键部件位置。
2. 第二优先：材质与表面质感、固有色。
3. 第三优先：装饰细节、小文字、边角元素。

提示词必须按此顺序表达；不能把材质、装饰排到轮廓之前。

## 产品锁块

把身份锁压缩成一段**固定文字**，系列里每条提示词原样复用：

```text
产品锁块：[产品整体形态与比例] + [颜色分区] + [关键部件与连接关系] + [材质与光泽] + [品牌元素（或「隐去 logo」）]
```

## 产品自然落地规则（真实生活实拍感）

产品要像真实物体摆在生活场景里，不是贴图或漂浮物：

- **尺度合理**：与场景参照物（家具、人、道具）比例正确，不偏大偏小。
- **接触面正确**：底面/支撑面与桌面、台面、地面、手中真实接触，有正确落点。
- **透视一致**：产品透视与场景机位/焦段一致。
- **遮挡合理**：前景遮挡自然（如手持、桌沿），但不遮住关键识别特征（logo、轮廓、核心部件）。
- **光影匹配**：产品的受光方向、色温、明暗与场景一致；有接触阴影、环境反光。

## 正向锁定 + 负向防线

- **正向**：产品锁块逐项进入提示词，明确写「产品保持原结构、原颜色分区、原材质」。
- **负向**（放提示词末尾，只针对当前产品）：`避免改变产品的外形、比例、部件、颜色、材质、logo；避免产品变形、缺件、换材质、换色、复制产品、添加不存在的文字标识；避免产品像贴图或漂浮物；避免前景道具遮挡产品关键识别特征。`

## 产品可见性

- 产品必须是画面可识别的主体或明确焦点；关键识别特征（logo、轮廓、核心部件）不被前景遮挡。
- 写清产品在场景中的位置、朝向、大小、机位角度，避免模型把产品画成「别的样子」。

## 可选加固建议（只给建议，不自动生图）

由于本技能只出提示词，可附一句使用建议：把产品图作为绘画模型的参考图/垫图（Midjourney `--iw`、Stable Diffusion `ip`/垫图、即梦/可灵「参考图」等）能更稳地保形保材质；纯文生图时产品锁块 + 自然落地 + 负向防线是主要保真手段。
