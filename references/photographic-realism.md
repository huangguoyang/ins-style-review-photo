# 真实生活摄影、自然配色与反渲染反商业词库

## 目标

把「真实生活摄影」确立为默认成像取向，并给出手机随手拍的摄影语言、生活痕迹来源与自然配色方法。目标是让提示词导向「像真人用手机在真实生活场景里拍出来的照片」，而不是 3D 渲染、插画、CG 质感，也不是影棚精修的商业广告。

## 默认取向：真实生活摄影

- 除非参考图或用户明确指向别的媒介，否则默认是**真实生活摄影、手机随手拍**。
- 用「手机实拍」的措辞锚定成像系统，避免落入渲染感：写「真实摄影、自然透视、环境反光、接触阴影、生活痕迹、轻微噪点、自然景深」，而不是「3D 渲染、CG、插画、数字艺术、影棚布光」。
- 允许并保留真实摄影的「不完美」：轻微噪点、自然景深虚化、自然阴影软边、反光/倒影、克制的颗粒与生活痕迹——这些正是真实质感的来源。

## 手机随手拍的摄影语言

- **自然光为主**：窗光、阴天散射光、台灯暖光、户外日光、黄昏侧光；不用影棚均匀布光，光源方向明确即可。
- **生活痕迹**：褶皱、灰尘、轻微使用感、桌面杂物、自然反光——点到为止，不堆砌、不脏乱。
- **软装密度与陈设语言**：真实生活里会存在的东西（一本书、一杯咖啡、一株绿植、手机、钥匙），有尺度参照物，产品「被使用/被陈列」而非「被摆拍」。
- **手持与人物互动**：手持产品、手部特写、人物使用产品的自然抓拍瞬间，不做作、不摆拍。
- **机位与焦段感**：俯拍桌面 / 平视 / 斜拍 / 手持近景 / 微距特写；手机广角的空间感或近距的浅景深。
- **景深**：浅景深虚化背景突出产品，或大景深交代完整生活场景；保持自然，不追求商业奶油散景。

## 自然配色方法论

真实感不来自「颜色本身」，而来自「颜色与材质、光线配合出的自然」。写配色时永远同时写材质与光。

- **骨架**：黑白灰/中性色/木色/生活常见的低饱和色打底（占最大面积），1 个主色 + 1 个点缀色形成记忆点。
- **自然**：饱和度接近真实生活、不浓艳；材质本色优先，避免高饱和撞色与商业滤镜感。
- **关系**：邻近色为主 + 少量对比色；冷暖呼应；明度对比负责层次，色相对比负责情绪。
- **落地**：参考色卡只取真正影响画面的 4–6 色，标注作用与大致占比；黑白灰图也要区分背景、主体、阴影、高光。

## 生活氛围感来源（进入场景与光线）

- 光：自然光/居家光方向明确，色温统一，明暗有层次，允许轻微过曝/欠曝的自然感。
- 层次：前中后景 + 空气透视 + 景深，避免「贴图感」。
- 生活感：克制的陈设与生活痕迹，点到为止，不堆砌。
- 真实：轻微噪点、非完美构图、生活化的背景，避免塞满、避免完美对称。

## 反渲染 + 反商业词库

正向用实拍词，负向排渲染词与商业精修词：

- **避免（渲染/塑料感）**：塑料感、CG 感、游戏引擎、3D 渲染、超光滑、无阴影、漂浮、贴图、过饱和、色块生硬。
- **避免（商业广告感）**：影棚均匀布光、精修海报、完美对称构图、过度磨皮、模特摆拍、商业 hero shot、影棚渐变背景。
- **正向**：真实摄影、手机实拍、自然透视、接触阴影、环境反光、材质纹理、轻微噪点、自然景深、时间感、生活痕迹、手持抓拍。
