# 输出合同与提示词组织

## 目标

把「真实生活风格母版 + 产品身份锁 + 真实场景方案」组装成可直接复制的中文生成提示词，并保证系列一致、产品保真、真实生活质感。

## 默认交付模板

```text
# 真实生活风格母版（跨参考图共性）
[拍摄感/媒介、成像签名、场景类型、色彩系统、光线系统、材质质感、构图语言、氛围调性]
风格前缀块：...

# 产品身份锁（不可改变）
[结构/轮廓、材质、颜色、品牌元素]
产品锁块：...

# 真实场景方案（系列一致，仅场景变化）
## 场景 1：{叙事一句话}
审美要点：...
产品位置：...
人物互动：...
完整提示词：...

## 场景 2 / 3 ...

# 使用建议
画幅默认 3:4 竖屏；可选：把产品图作为参考图/垫图以更稳保形。
```

## 单条提示词组织顺序

```text
拍摄感与整体成像签名（风格前缀块，含"手机随手拍真实生活摄影"基调）
→ 画幅、机位、构图与空间骨架
→ 产品身份锁（结构/材质/颜色）
→ 场景与叙事（真实环境、道具、前中后景、人物互动）
→ 光线与色彩（自然光/居家光优先）
→ 材质与成像质感（真实纹理、生活痕迹）
→ 产品保真防线（负向）
```

## 要求

- 用一段连续、可直接复制的中文自然语言，不输出模块标签、项目符号、英文键或占位符。
- 风格前缀块与产品锁块在系列内逐条**原样复用**，只有场景叙事块变化。
- 一个事实只进入一次提示词，不重复堆同义词。
- 不编造品牌、镜头型号、身份或不可见区域。
- 保真防线放末尾，只针对当前产品，不写通用负面词清单。
- 真实生活基调贯穿每条：自然光、真实场景、真实材质、生活痕迹；避免出现影棚光、过度精修、完美对称等商业广告词。

## 覆盖审计（输出前逐项核对）

1. 风格前缀块是否在每条开头原样复用。
2. 产品锁块是否在每条中原样复用。
3. 画幅是否默认 3:4（或按用户指定）。
4. 产品结构/材质/颜色是否进入正向锁 + 负向防线。
5. 场景变化是否只发生在叙事/构图/环境/人物互动层，未改变风格母版。
6. 是否新增了母版/锁块之外的无证据事实。
7. 保真防线是否紧凑且针对当前产品。
8. 每条是否贯彻「手机随手拍真实生活摄影」基调（无影棚光/过度精修/商业广告感）。

任一生成敏感项未覆盖时，先修订提示词再交付。
