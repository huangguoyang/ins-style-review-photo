# 输出合同与提示词组织

## 目标

把「真实生活风格母版 + 产品身份锁 + 真实场景方案」组装成可直接复制的中文生成提示词，并保证系列一致、产品保真、真实生活质感。

## 默认交付模板

```text
# 真实生活风格母版（跨参考图共性）
[拍摄感/媒介、成像签名、场景类型、色彩系统、光线系统、摄影语言、材质质感、氛围调性]
风格前缀块：...

# 产品身份锁（不可改变）
[结构/轮廓、颜色分区、材质、品牌元素]
产品锁块：...

# 真实场景方案（系列一致，仅场景变化）
## 场景 1：{方向 + 叙事一句话}
审美要点：...
产品位置：...
人物互动：...
完整提示词：...

## 场景 2 / 3 ...

# 使用建议
画幅默认 3:4 竖屏；可选：把产品图作为参考图/垫图以更稳保形。
```

## 单条提示词组织顺序

```text
拍摄感与整体成像签名（风格前缀块，含「手机实拍」定位）
→ 画幅、机位、焦段感、构图与空间骨架
→ 产品身份锁（结构/颜色分区/材质）
→ 产品自然落地（尺度、接触面、透视、光影匹配）
→ 场景与叙事（真实环境、道具、前中后景、人物互动）
→ 光线与色彩（自然光优先，含自然配色骨架）
→ 材质与成像质感（真实纹理、生活痕迹、反渲染）
→ 产品保真防线（负向）
```

## 要求

- 用一段连续、可直接复制的中文自然语言，不输出模块标签、项目符号、英文键或占位符。
- 风格前缀块与产品锁块在系列内逐条**原样复用**，只有场景叙事块变化。
- 一个事实只进入一次提示词，不重复堆同义词。
- 默认用「手机实拍」措辞，避免渲染感；写光的方向、景深、配色骨架、生活痕迹，不写空词。
- 不编造品牌、镜头型号、身份或不可见区域。
- 保真防线放末尾，只针对当前产品，不写通用负面词清单。
- 真实生活基调贯穿每条：自然光、真实场景、真实材质、生活痕迹；避免出现影棚光、过度精修、完美对称、CG/渲染/塑料感等词。
- 出现人物时限定欧美人物（欧美面孔、欧美肤色与五官特征、欧美生活方式），不做亚洲/东亚面孔。

## 覆盖审计（输出前逐项核对）

1. 风格前缀块是否在每条开头原样复用，是否锚定「手机实拍」。
2. 产品锁块是否在每条中原样复用（含颜色分区）。
3. 画幅是否默认 3:4（或按用户指定）。
4. 产品结构/颜色分区/材质是否进入正向锁 + 负向防线。
5. 产品自然落地（尺度/接触/透视/光影）是否写进每条提示词。
6. 场景变化是否只发生在叙事/构图/环境/人物互动层，未改变风格母版。
7. 是否新增了母版/锁块之外的无证据事实。
8. 保真防线是否紧凑且针对当前产品。
9. 每条是否贯彻「手机随手拍真实生活摄影」基调（无影棚光/过度精修/CG/渲染/塑料感）。
10. 出现人物时是否限定欧美人物（无亚洲/东亚面孔）。

任一生成敏感项未覆盖时，先修订提示词再交付。
