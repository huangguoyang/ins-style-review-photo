# 真实生活风格母版

## 目标

从多张参考图提炼一段「跨图共性、可复用」的真实生活摄影视觉 DNA，压缩成风格前缀块，供系列里每一条提示词开头原样复用。它不是任何一张参考图的复述，而是多图之间的「交集」。核心落点是「手机随手拍的真实感」——自然光、真实场景、真实材质、生活痕迹，而不是商业广告质感。

## 交集而非并集

- 出现在**多数**参考图里的特征 → 进入母版。
- 只在**单张**图出现、且用户没有点名 → 不进母版。
- 只在单张图出现、但极强且用户点名参考 → 作为「点睛」进入母版，并标注「仅来自参考图 N」。
- 参考图之间互相矛盾（如有的暖、有的冷）时，不强行平均；优先采信用户点名的图，或写明「主体倾向 X，局部保留 Y」。

## 提炼维度

按这八个维度逐项观察，每个有证据的维度才写，不凑齐：

1. **拍摄感与媒介**：手机随手拍 / 数码相机生活照 / 胶片感 / 拍立得感 / 记录式抓拍；真实生活摄影还是商业精修。这是本技能的第一落点——优先识别「手机拍摄感」的证据（自然颗粒、非棚拍光、生活化取景）。
2. **场景类型**：参考图里产品所处的真实环境——居家（书桌/床头/沙发/厨房）、桌面平铺、户外（街拍/公园/咖啡厅/阳台）、手持自拍、通勤路上。场景类型是母版的硬信息，系列里每条提示词都继承它，只换具体场景。
3. **色彩系统**：主色、辅色、点缀色；冷暖倾向、饱和度、明度关系、黑白灰占比。真实生活照通常饱和度自然、不浓艳；可提取 4–6 个近似 HEX 参考色（作用 + 大致占比）。
4. **光线系统**：自然光方向、软硬、色温、曝光；窗光/阴天散射光/台灯暖光/户外日光；是否有明显阴影、逆光、顶光。真实生活照多是自然光或居家灯光，非影棚均匀布光。
5. **材质与表面质感**：真实材质纹理、自然颗粒、轻微噪点、柔焦、景深、反光特性；是否有生活痕迹（褶皱、灰尘、使用感）。
6. **构图语言**：景别、机位（俯拍桌面/平视/斜拍/手持近景）、主体占比、负空间、前中后景、是否有前景遮挡（手、桌沿、道具）。
7. **氛围与叙事调性**：情绪、生活气息、真实感、亲切感的来源（不是「真实」二字，而是它怎么做到的——自然光、生活化背景、人物互动、日常瞬间）。
8. **成像签名**：见下节四层分离。

## 成像签名四层分离

把成像机制分成四层判断，不互相覆盖：

1. **固有属性**：物体原本的颜色与材质。
2. **光线层**：光源方向、色温、软硬、阴影、轮廓光（自然光/居家光优先）。
3. **曝光层**：全局/局部曝光、动态范围、高光是否接近溢出、暗部是否压低；真实生活照常带轻微过曝或欠曝的自然感。
4. **后期/渲染层**：微对比、锐化、柔焦、颗粒、色偏、光晕、压缩、滤镜感（如 INS 常见滤镜）、扫描/拍立得边框。

跨层描述可以同时成立。同一层出现冲突时回到参考图证据重判。成像签名写「成像系统」而非主题内容。

## 风格前缀块

把母版压缩成一段**固定文字**，作为系列里每条提示词的开头原样复用：

```text
风格前缀块：[拍摄感与媒介] + [成像签名/整体气质] + [场景类型基调] + [色彩系统] + [光线系统] + [材质质感]
```

要求：

- 用连续中文自然语言，不出现模块标签、英文键或占位符。
- 只写有画面证据的事实；「真实感、氛围感、生活化」等空词换成可执行描述（如「窗边自然光、桌面有轻微生活痕迹、非棚拍」）。
- 明确写「手机随手拍的真实生活摄影」这一基调，除非用户明确要求别的媒介。
- 不承诺还原原作者提示词；交付的是基于画面证据重建的高还原生成指令。
