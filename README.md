# INS 风格评论图（ins-style-review-photo）

把「参考图的真实生活摄影风格」×「产品图的主体」合成 INS/小红书评论图、买家秀、种草实拍风格的提示词。只输出可复制的提示词，不自动生图。

## 它能做什么

- 从**多张参考图**提炼统一的「真实生活风格母版」（拍摄感、场景类型、光线、材质、色彩、构图），取交集而非并集。
- 从**产品图**锁定「产品身份」（结构/外观/材质/颜色），严格保持不变。
- 沿**叙事 × 生活场景**两个轴衍生多个真实场景（支持产品与人物互动），产出系列一致、审美一致的提示词。
- 默认画幅 3:4 竖屏（小红书/INS 通用），支持 MJ / FLUX / SD / 即梦等文生图工具。
- 核心是**真实生活摄影**而非商业大片：自然光、真实场景、真实材质、生活痕迹、手机拍摄感，场景风格由参考图定义。

## 触发方式（给 Claude 用的）

> 给我的产品做几张这种生活感的图
> 要真实质感的评论图 / 种草实拍 / 随手拍风格
> 把产品放进真实生活场景里，拍出手机随手拍的感觉
> 参考这些图，给我的产品做 INS 风 / 小红书图 / 买家秀

## 输出示例

```text
# 真实生活风格母版（跨参考图共性）
风格前缀块：...

# 产品身份锁（不可改变）
产品锁块：...

# 真实场景方案（系列一致，仅场景变化）
## 场景 1：{叙事一句话}
审美要点：...
产品位置：...
人物互动：...
完整提示词：...

# 使用建议
画幅默认 3:4 竖屏；可选：把产品图作为参考图/垫图以更稳保形。
```

## 安装（Cherry Studio）

1. 下载本仓库。
2. 将整个文件夹放入 Cherry Studio 技能目录：`Data\Skills\ins-style-review-photo\`。
3. 在 Cherry Studio 技能面板启用本技能（或重启后生效）。
